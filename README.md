
This project is a Python-based File Integrity Monitoring (FIM) system
that detects unauthorized file changes in real time.

The system monitors files and folders, generates SHA-256 hashes,
detects modifications, deletions, and new file creation events,
and logs suspicious activity.


Features:

- Real-time file monitoring
- SHA-256 hashing
- File modification detection
- File deletion detection
- New file detection
- Security logging
- Ignore rules
- Threat severity levels
- Error handling

Technologies:


- Python
- watchdog
- hashlib
- logging


How to install:

Install dependencies:


pip install -r requirements.txt


Run the application:


python app.py
